# ✈️ Air Supreme - 3D 空战游戏

**[English](README.md) | [简体中文](README.zh-CN.md)**

一款使用 Three.js + TypeScript 开发的 3D 飞机空战游戏，支持桌面和移动端。当前版本是十章故事战役 **AIR SUPREME · 天穹之战**：十个关卡与十种环境、十个 Boss、三大阵营的地面 / 海上 / 空中单位、五种随剧情解锁的特殊武器与热焰弹、可切换的第一人称座舱与第三人称追尾视角、关卡中途自动存档与继续战役，以及章节之间的机库整备。游戏默认英文界面，在设置里一步即可切换为简体中文；无线电角色与剧情旁白提供英文与普通话两套配音。Boss 模式、试玩关卡、事件波次、暂停舱与模型预览均保留。

## 🎮 游戏特色

### 当前内容概览

- **十章故事战役** — 10 个关卡、10 个 Boss，章节卡片、无线电对话、任务结算与结局
- **默认英文，可选中文** — 在开始菜单或暂停设置的 **语言**（Language）一行切换；菜单、HUD、无线电与配音立即跟随
- **英文与普通话配音** — 无线电角色与剧情旁白都有配音，屏幕文字即字幕，配音音量单独可调
- **具名僚机** — 渡鸦从第 1 章起随队，雨燕第 3 章加入
- **普通模式 / Boss 模式** — Boss 模式可直接挑战十个 Boss 中的任意一个
- **第一人称座舱 / 第三人称追尾视角** — 随时按 **V**（移动端「视角」/ VIEW 按钮）切换
- **五种特殊武器 + 热焰弹**，随剧情推进逐个解锁
- **地面、海上、空中单位**，分属敌方、友军、平民三大阵营

- **章节之间的机库整备** — 分级升级，上限随章节逐步开放
- **程序化配乐** — 23 首曲目与 7 个刺激音全部由 Web Audio 实时合成，另有全新音效
- **试玩关卡开关**
- **暂停舱与局内结算**
  - ESC / P 打开暂停舱；桌面 U 先暂停再开升级商店
  - 失败显示 `MISSION FAILED`、通关显示 `MISSION COMPLETE`（中文界面为「任务失败」/「任务完成」），可再来一局或返回菜单

  - 页面以 `<html lang="en">` 和英文的加载画面、触控按键文字发布；`src/main.ts` 在任何界面渲染之前应用已保存的语言，并保持 `<html lang>` 同步

  - 菜单空闲与开始前会预热深层运行时 chunk

  - 精英歼灭
  - 限时拦截
  - 护送防守
- **模型预览**

### 🌍 关卡环境（Worldscape + 环境模块）

第 1-5 关由程序化 Worldscape 引擎生成（种子化噪声高度场 + 群落顶点着色 + 实例化植被）；第 6-10 关在 `src/features/terrain/environments/` 下有专属环境模块：

1. **湖畔晨曦** - 湖谷场景：码头、村落、睡莲、2.4 万株风摆草、松林与阔叶树、合并球簇实例化云
2. **沙漠风暴** - 沙丘高度场，暖色岩石，旱草点缀，仙人掌群落
3. **雪山之巅** - 雪线山脊，冰川蓝湖潭，谷地抬升，云雾缭绕
4. **深海决战** - 远洋晴昼（环境光全面提亮），菲涅尔/岸沫着色器水面，小岛散布
5. **城市废墟（纽约化）** - 中央公园草甸 + 帝国大厦式尖塔 / 克莱斯勒式塔冠 / 双子玻璃塔，布鲁克林式悬索桥，双层高架快速路，高架环线列车（动画车流与亮窗列车），街灯 + 广告牌 + 近翻倍窗灯密度
6. **熔炉之心** - 火山岛兵工厂：峰顶熔岩湖与冲天火山灰柱的主火山，三条熔岩河注入大海（入海处蒸汽翻滚），冷却玄武岩上脉动的发光裂纹，神谕兵工厂（冷却塔、高炉、火炬塔）；火山灰缓落、余烬上升。岛外海域为可航行水面。
7. **极光冰海** - 极夜笼罩的北冰洋：冰架与平顶 / 尖顶冰山之间的墨色海面，漂移浮冰、海面低雾，带雷达罩与探照灯的冰封前哨站，极光帘幕与轻雪。
8. **雷霆峡谷** - 三条蜿蜒的层理砂岩峡谷（阶梯崖壁与平顶台地），暴涨的红泥河（可航行），车队土路，沿崖壁倾泻的暴雨瀑布，神谕的特斯拉收集塔；雷暴天气的闪电劈向真实地表。
9. **天梯之巅** - 两万米高空、落日下的云海甲板：天梯轨道电梯的光纤主干、升降舱、六根支柱托起的光环平台与锚塔。云海是坠毁面——飞进云海即坠毁。
10. **神谕核心** - 陨石坑中央的黑曜城堡：阶梯状坑壁，四条熔岩裂谷与四条青色能量导管汇向要塞，导能尖碑为核心光柱输能；最终决战在核心井上空展开。

**天气**：预设 `clear`、`cloudy`、`mist`、`windy`、`sandstorm`、`snow`、`storm`、`smog`，新增 `ash`（火山灰缓落 + 余烬上升）与 `aurora`（极光带 + 轻雪）；`storm`（雨幕 + 雷暴闪电）用于峡谷。**动态云**随风漂移、环绕回卷、垂直浮动、随天气色调调制，阴暗天气下渲染更柔和。

**Worldscape 技术栈**（`src/features/terrain/worldscape/`）：
- 种子化 simplex / fbm / ridged 噪声高度场
- 群落顶点着色
- 波浪 / 菲涅尔 / 岸沫着色器水面
- 实例化松林 / 阔叶树 / 岩石 / 2.4 万风摆草
- 合并球簇实例化云
- 风摆与积雪着色器注入

### 多样化的敌人 AI

- **侦察机 (Scout)** - 快速但脆弱，高闪避
- **战斗机 (Fighter)** - 平衡型，标准战斗单位
- **重型轰炸机 (Heavy Bomber)** - 慢速但高血量，高伤害
- **狙击机 (Sniper)** - 远距离精确攻击
- **王牌飞行员 (Ace)** - 高难度，聪明 AI，使用高级战术

敌机会前瞻并爬升避让高耸地形（峡谷崖壁、火山、天梯支柱、城堡），不会钻入地表；只在一定距离内开火；被 EMP 瘫痪时只能惯性滑行。敌机强度随章节提升（`src/core/Difficulty.ts` 的 `getLevelScaling`，读取一张逐关数值表，再乘以玩家选择的难度档：简单、普通、标准、困难、专家，英文界面为 Very Easy、Easy、Normal、Hard、Expert）。默认的「标准」档由只在开发构建中提供的脚本飞行员平衡测量工具实测调校。

### 🚛 地面、海上与空中单位

17 种单位与敌机并肩作战，按波次部署（`src/features/units/UnitDeployments.ts`），各有独立行为；第一次遭遇某类单位时，无线电会给出提示。

| 阵营 | 对你意味着什么 |
| ---- | -------------- |
| **敌方** | 计入波次清场——本波敌机**和**敌方单位都被消灭才算过波（只剩零星单位时，超过时限后自动放行）。击毁可得分。 |
| **友军** | 与你并肩作战。护送目标（车队、运输机）安全抵达时有奖励分；亲手击毁友军单位会扣分，所有友军损失都计入任务结算。友军预警机或护卫舰被击毁时，由它们自己的机组 / 舰员（灯塔、壁垒）在无线电里报告。 |
| **平民**（中立） | 不与任何阵营敌对，但可能被卷入交火。第一次误伤会触发无线电停火警告；亲手击毁平民会扣分，所有平民损失都计入任务结算。 |

敌方单位：

| 单位 | 作战域 | 行为 |
| ---- | ------ | ---- |
| 主战坦克 | 地面 | 追踪你并开炮 |
| 地空导弹车 | 地面 | 先锁定再发射——锁定期间 HUD 告警，用热焰弹应对 |
| 双联高炮 | 地面 | 提前量弹幕；你不在射界时转而射击友军战机 |
| 雷达站 | 地面 | 观测站：只要还有一座雷达站，敌机命中率就更高 |
| 高速炮艇 | 海上 | 一边蛇形高速机动一边开火 |
| 导弹护卫舰 | 海上 | 垂直发射导弹 + 近防炮 |
| 攻击潜艇 | 海上 | 上浮锁定并发射导弹后再下潜；只有上浮时才能被击中（潜航时在雷达上显示为声呐接触） |
| 武装直升机 | 空中 | 贴地飞行，用火箭巢与机炮侧滑扫射；被击落时自旋坠落 |
| 战略轰炸机 | 空中 | 高空直线航路，对友军地面 / 海上单位投弹；尾炮自卫 |

友军单位：友军车队（护送目标）、友军护卫舰（近防炮拦截导弹，并对空、对舰射击）、友军预警机（存活期间扩大你的雷达范围）、友军运输机（护送目标）。平民单位：民航客机、民用货轮、民用卡车——沿各自航线行进后离开战场。

**僚机**：最先升空的友军战机是你的具名僚机——渡鸦从第 1 章起、雨燕从第 3 章起（`WINGMEN`，`src/core/campaign/Wingmen.ts`）；其余友军战机是普通友军。僚机的血条显示其呼号。雨燕入列时会在无线电里报到；僚机被击落时由另一名僚机播报（不在空中时由天穹指挥部播报），被击落的僚机本关不再出现（下一关或从检查点继续时全员归队）。

**雷达图例**：敌机 = 红点 · 敌方地面单位 = 红色方块 · 敌方舰艇 = 红色菱形 · Boss = 大红点 + 外环 · 友军战机 = 金点 · 友军单位 = 金色三角 · 平民 = 灰色空心圆（勿开火）· 道具 = 绿点 · 正在从传送门进场 = 琥珀点。

### 🚀 导弹系统

- **智能锁定** - 按住导弹键（M或右Shift）锁定目标
- **锁定进度** - 1.5 秒锁定时间（可升级），TRACK 菱形+弧（`--hud-weapon` `#FFB347`）
- **锁定范围升级** - 新增独立升级项，满级后锁定圈可扩大到基础值的 `2x`
- **视觉提示** - SEARCH 空心虚线环 / TRACK 菱形+弧 / LOCK 薄荷绿 `#5CFFB0` / BREAK 威胁红 `#FF4D4D` / DRY `NO MSL`
- **追踪导弹** - 自动追踪目标，目标被毁后自动重新锁定最近敌人
- **资源管理** - 初始 2 发，自动补给（每 7.5 秒恢复 1 发，最多 5 发，可升级）
- **弹药提示** - 导弹耗尽时按下 M 键会显示 `NO MSL`（不是 `NO MISSILE`）
- **UI 进度条** - 右上角显示白色进度条，距离下一发导弹的进度
- **伤害** - 导弹伤害 50 点（比机炮高 4 倍）
- **玩家导弹外观** - AIM-120 风格一体车削弹体，黑雷达罩 / 滚转色带 / 铭文 / X 翼布局

### ☄️ 特殊武器与热焰弹

特殊武器随剧情解锁，按 **F** 发射；**1-5** 直接选择，**Tab / X** 循环切换。每件武器有各自的弹药、装填、热量或蓄力，显示在 HUD 挂架面板上。特殊武器会伤及敌方与平民目标（平民附近注意射界）；友军单位与玩家自己永远不会受伤。

### 🛠️ 升级与机库

得分会转化为升级点（⭐），越往后的章节每次击杀得分越高。章节之间会打开 **机库整备**（英文界面为 Refit & Rearm），点 **出击**（Launch）进入下一章；对局中也可以在暂停舱里升级（**ESC** / **P** → **升级**；桌面端 **U** 先暂停再直接打开商店）。未用完的升级点会保留。

共 14 条升级线。每条升级线都有 **本章上限**，随战役推进逐步开放，机体成长与难度同步：

| 分组 | 升级线 | 层级 | 第 *n* 章上限 |
| ---- | ------ | ---: | ------------- |
| 核心 | 最大生命值、飞行速度、射速、武器伤害、锁定范围、导弹装填、导弹锁定 | 10 | `min(10, n + 1)` |
| 防御 | 复合装甲、热焰弹挂架 | 5 / 4 | `min(满级, ceil(n / 2) + 1)` |
| 特殊武器 | 火箭、激光、蜂群、轨道炮、EMP | 各 5 | 武器解锁前锁定，之后 `min(5, n − 解锁章节 + 2)` |

| 升级       | 基础值 | 最大值 | 每档变化 |
| ---------- | ------ | ------ | -------- |
| 最大生命值 | 200    | 400    | +20      |
| 飞行速度   | 45     | 85     | +4       |
| 射速       | 0.30s  | 0.10s  | -0.02s   |
| 武器伤害   | 12.5   | 30     | +1.75    |
| 锁定范围   | 1.0x   | 2.0x   | +0.1x    |
| 导弹装填   | 7.5s   | 2.5s   | -0.5s    |
| 导弹锁定   | 1.5s   | 0.5s   | -0.1s    |
| 复合装甲   | 0%     | 减伤 40% | +8%    |
| 热焰弹挂架 | 2 发   | 6 发   | +1       |

每档花费随层级上升，当前花费见 `src/features/upgrade/UpgradeSystem.ts` 的 `UPGRADE_CONFIGS`。从第 1 章以外的章节开局（普通模式或 Boss 模式）会补发一笔起步升级点并先进入机库；本章上限依然生效。

### 💾 自动存档与继续战役

- 普通模式下，入关、每一波结束后以及 Boss 战之前都会写入检查点，HUD 弹出「已自动保存」（Autosaved）提示
- 存在检查点时，开始菜单显示 **继续战役**（Continue Campaign）按钮，并标注如 `第6关 · 熔炉之心 · 第3波`（英文界面为 `Ch. 6 · Heart of the Forge · Wave 3`）；`MISSION FAILED` 结算界面提供 **从检查点继续**（Continue from checkpoint）
- 检查点会还原分数、生命、导弹、升级、已解锁武器及其弹药、热焰弹充能、视角与本局统计，并回到存档的波次或 Boss 战前
- 普通模式新开一局会清除旧检查点；打完第 10 章会标记战役通关并清除检查点；Boss 模式不写检查点
- 存档保存在 `localStorage`（`air-supreme:campaign-save`；通关记录、最高分与到达过的最高关卡在 `air-supreme:campaign-progress`）

### 🎙️ 角色配音

- 每一句无线电台词和每一段剧情旁白都有 **英文** 与 **普通话** 配音；配音跟随 **语言** 设置——切换语言时正在说的那句会停下，之后的台词改用新语言配音
- 无线电配音经过按说话人调校的电台滤波（指挥部与预警机频段更宽、更干净，座舱、护卫舰与民用频道更窄、底噪更重），每句结尾有一声静噪尾音；剧情旁白（天穹）不加电台效果。每句配音都做响度匹配，说话时音乐自动压低、说完后恢复
- 屏幕文字即字幕：无线电台词会停留到配音说完，剧情卡片的打字机按旁白节奏打字

- 紧急告警依旧会打断无线电，被中途打断的台词会从头重播；暂停游戏时配音暂停，继续后从断点接着说
- 配音由 AI 生成（ElevenLabs `eleven_v4`，每句一次生成），文件带 C2PA 来源凭证；音频文件、清单与逐文件来源记录位于 `public/voice/`，详见 [`docs/voice-lines.md`](docs/voice-lines.md)

按键文字随语言设置变化（括号内为英文界面的文字）：

## 🎨 游戏机制

### 波次系统

- 每个关卡包含多个普通波次和事件波次；地面、海上、空中单位与敌机一同部署
- 敌人分批刷新，不会同时出现太多
- 本波敌机与敌方单位全部被消灭才算过波
- 波次间隔期间可以收集道具
- 完成所有波次后进入当前关的 Boss 战，随后是任务结算与机库

### 碰撞系统

- 玩家子弹 vs 敌人、单位与 Boss 部件——命中按目标的命中半径判定，大型舰船与 Boss 部件打在哪里就算在哪里
- 敌人子弹 vs 玩家与友军单位（友军子弹不伤玩家）
- 玩家 vs 道具
- 玩家 vs 活地形/水面：世界 `Y <=` `getCrashSurfaceY`（无地形时 `WORLDSCAPE_WATER_Y` `-48`）则坠毁；所有关卡（包括第 9 关的云海）都参与采样
- 每关开局都朝向一条无遮挡的航道；坠毁复活时会回到地形上方，并避开前方的上升地形

### JSON 配置系统

游戏支持通过 JSON 文件进行外部配置，无需修改代码即可调整参数：

**配置文件位置**: `public/config/game-config.json`

```json
{
  "player": {
    "maxHealth": 200,
    "speed": 45,
    "fireRate": 0.3,
    "damage": 12.5
  },
  "enemy": {
    "spawnInterval": 2000,
    "maxCount": 10
  },
  "game": {
    "difficulty": "normal"
  }
}
```

**在代码中使用 ConfigLoader**:

```typescript
import { configLoader } from '@/core/utils/ConfigLoader';

async function initGame() {
  await configLoader.load();
  const playerConfig = configLoader.getPlayer();
  const enemyConfig = configLoader.getEnemy('FIGHTER');
}
```
